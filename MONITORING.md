# EVRIKA Monitor

EVRIKA Monitor получает объявления из почтовых уведомлений сохранённых поисков Авито. Администратор может отфильтровать входящие объявления, посмотреть историю цены и отправить объект в работу. Страницы объявлений открываются по нажатию пользователя.

## Установка и запуск

1. Установите зависимости командой `npm ci` в папке проекта. Если PowerShell блокирует скрипты npm, используйте `npm.cmd ci`. Проект поддерживает Node.js 22 и новее.
2. Для новой базы выполните обычную настройку CRM и `npm run setup`. При первом запуске обновлённого сервера миграция создаёт таблицы мониторинга и добавляет тип сделки «Аренда». Пользователю PostgreSQL нужны права на создание таблиц и изменение ограничений таблицы `tasks`.
3. Создайте отдельный ключ шифрования.

   ```sh
   node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
   ```

4. Запишите результат в `MONITOR_ENCRYPTION_KEY` в локальном `.env` или секретах окружения Render. Храните резервную копию ключа отдельно от базы. При потере ключа сохранённые пароли и токены потребуется ввести заново.
5. Запустите `npm start`. Войдите как администратор и откройте «Мониторинг → Настройки мониторинга».

`imapflow` выполняет команды IMAP, `mailparser` декодирует MIME, `cheerio` разбирает HTML без выполнения скриптов, `ipaddr.js` проверяет IP-адреса до подключения.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `MONITOR_ENCRYPTION_KEY` | 32 случайных байта в Base64. Нужна для сохранения новых почтовых секретов и запуска мониторинга. Без неё остальные функции CRM доступны. |
| `MONITOR_IMAP_HOSTS` | Дополнительные точные публичные DNS-имена IMAP-серверов через запятую. Gmail, Яндекс Почта и Mail.ru уже разрешены. |
| `MONITOR_IMAP_INTERFACE` | Имя сетевого адаптера для сокетов IMAP, например `Ethernet`. Если переменная пуста, используется обычная маршрутизация сервера. |
| `MONITOR_TRUSTED_AUTHSERV_IDS` | Дополнительные точные имена из заголовка `Authentication-Results` через запятую. Указывайте серверы, которым доверяете проверку входящей почты. |
| `MONITOR_GOOGLE_CLIENT_ID` | ID OAuth-приложения Google при использовании Gmail OAuth. |
| `MONITOR_GOOGLE_CLIENT_SECRET` | Секрет OAuth-приложения Google при использовании Gmail OAuth. |

Для Neon используется существующая переменная `DATABASE_URL`, для локальной PostgreSQL — `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` и `DB_PASSWORD`. Сохраните настоящий `.env` и добавьте в него только необходимые параметры. Секреты храните вне репозитория.

## Подключение ящика

1. На Авито сохраните поиск с нужными параметрами и проверьте, что электронные уведомления включены, если этот канал доступен для вашего аккаунта. Убедитесь, что хотя бы одно реальное письмо пришло. Выберите в CRM фактическую папку. Если нужно, на стороне почты настройте правило перемещения.
2. Нажмите «Добавить ящик», выберите провайдера и введите название, почту, логин и папку, например `INBOX`. По умолчанию резервная проверка выполняется каждые 60 секунд.
3. Создайте пароль приложения у провайдера и вставьте его в CRM. Двухфакторная аутентификация может оставаться включённой. Для другого провайдера оператор сервера сначала добавляет его хост в `MONITOR_IMAP_HOSTS`. Поддерживаются TLS на порту 993 и обязательный STARTTLS на порту 143.
4. Нажмите «Проверить подключение», «Сохранить настройки», затем «Запустить мониторинг». Для запущенного подключения можно запросить немедленную проверку. Между ручными запросами должно пройти 30 секунд.

Если локальный VPN перехватывает IMAP, задайте `MONITOR_IMAP_INTERFACE` в `.env` и перезапустите сервер CRM. Список имён адаптеров Windows показывает команда `Get-NetAdapter`. Параметр привязывает только IMAP к адресу выбранного адаптера. Работа прямого подключения зависит от маршрутизации и правил VPN на компьютере.

| Провайдер | Настройка |
| --- | --- |
| Gmail | `imap.gmail.com`, TLS 993. Используйте полный адрес и пароль приложения, если он доступен для аккаунта. [Справка Google](https://support.google.com/accounts/answer/185833) |
| Яндекс Почта | `imap.yandex.ru`, TLS 993. Включите IMAP в настройках почтовых программ и создайте пароль приложения. [Справка Яндекса](https://www.yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/mail-clients-troubleshooting) |
| Mail.ru | `imap.mail.ru`, TLS 993. Используйте пароль для внешней программы. [Справка Mail](https://help.mail.ru/mail/mailer/popsmtp) |

Если Gmail требует OAuth, создайте OAuth-клиент Google и получите refresh token с доступом к IMAP для нужного аккаунта. Получение согласия Google выполняется вне CRM. Когда переменные OAuth заданы на сервере, в форме можно выбрать Gmail OAuth и вставить refresh token. Сервер обновляет краткоживущий токен при подключении. Для остальных провайдеров предусмотрены пароли приложений. [Google OAuth](https://developers.google.com/identity/protocols/oauth2/web-server) · [OAuth для Gmail IMAP](https://developers.google.com/workspace/gmail/imap/xoauth2-protocol)

## Письма и диагностика

- Для проверки формата скачайте оригинал письма как `.eml`. Предпросмотр принимает файлы до 1 МБ, показывает найденные объявления, отсутствующие поля и результат проверки источника. Предпросмотр не создаёт карточки. Для прогона доступны [текстовый пример](tests/fixtures/monitor/text.eml) и [HTML-пример](tests/fixtures/monitor/html.eml).
- Автоимпорт требует одного отправителя из домена Авито и положительной проверки DKIM или DMARC по этому домену в первом заголовке `Authentication-Results`. При ручной настройке `MONITOR_TRUSTED_AUTHSERV_IDS` сверяйте его значение с верхним заголовком, добавленным принимающим сервером. Этот сервер должен удалять поддельные заголовки со своим именем. Пересылаемые письма и уведомления без подходящей проверки могут отклоняться.
- Поддерживаются прямые HTTPS-ссылки на карточки Авито. Почтовые редиректы не открываются автоматически и могут не распознаться. Карточка загружает распознанное фото с разрешённого CDN Авито только по кнопке «Показать фото».
- При первом запуске просматриваются уведомления за последние семь дней. Далее сервер сохраняет позицию IMAP, обрабатывает новые UID и восстанавливает работу после перезапуска. При поддержке IMAP IDLE поступление письма инициирует проверку. Папка открывается в режиме чтения.
- В журнале видны этапы подключения, отклонённые письма и ошибки разбора. При ошибке входа проверьте пароль приложения, логин и разрешение IMAP у провайдера. При ошибке TLS проверьте имя сервера, порт и исходящий доступ сети. Интервал переподключения увеличивается до пяти минут.
- Фильтры CRM применяются к уже полученным объявлениям. Исходные условия меняются в сохранённом поиске на Авито. Отсутствие нового уведомления не меняет статус публикации. При передаче в работу проверьте подстановку и заполните неизвестные поля задачи, в том числе телефон.

## Render и круглосуточная работа

1. Задайте на Render `DATABASE_URL`, действующий `JWT_SECRET` CRM и `MONITOR_ENCRYPTION_KEY`. При необходимости задайте дополнительные параметры мониторинга.
2. Используйте команду сборки `npm ci --omit=dev` и команду запуска `npm start`. После обновления дождитесь прохождения `/api/health`, затем проверьте IMAP через CRM.
3. Для режима 24/7 нужен постоянно работающий сервер. Бесплатный веб-сервис Render может засыпать после 15 минут без входящего трафика. При локальном запуске ПК и сервер Node.js должны оставаться включёнными. Закрытие Electron не останавливает отдельный сервер. [Документация Render](https://render.com/docs/free)

Интерфейс загружается с обновлённого сервера. Для нативных уведомлений Windows и открытия ссылок во внешнем браузере нужны новые сборки Electron. Команды сборки — `npm run build:admin` и `npm run build:employee`.

EVRIKA Admin сохраняет существующую настройку локального сервера. Для CRM, развёрнутой на Render, вход администратора доступен в браузере.

## Тестирование

`npm test` запускает тесты парсера, URL, шифрования, DNS, фильтрации и правил CRM. Для интеграционного теста задайте `MONITOR_TEST_DATABASE_URL` со строкой подключения к отдельной тестовой PostgreSQL. Тест создаёт собственную временную схему. Реальные уведомления Авито, авторизацию почтовых провайдеров и подключение к Neon проверяйте в целевом окружении.
