EVRIKA CRM — обновление 1.0.1 (интерфейс и завершение заказов)

1. Закройте окна CRM, остановите только сервер EVRIKA. Если сервер запущен через планировщик задач, остановите задачу «EVRIKA CRM Server» (не удаляйте её). Если сервер запущен из терминала, Ctrl+C. При фоновом запуске из Electron найдите и остановите только Node.js процесса проекта EVRIKA.
2. Скопируйте папки public, server, tests из архива в существующую папку EVRIKA-CRM, согласившись заменить совпадающие файлы. Не удаляйте сами папки проекта. Архив содержит только изменённые файлы, не весь проект.
3. Запустите EVRIKA Admin или восстановите запуск сервера тем же способом, что прежде. Перезапустите приложения сотрудников для обновления интерфейса.
4. Проверьте тестовую общую и личную задачу: «Сделка состоялась» и «Сделка сорвалась» скрывают заказ у всех сотрудников и оставляют его в «Клиенты → Завершённые» администратора; «Сделка перенеслась» остаётся активной. Данные, комментарии, авторы, даты и история не удаляются. Администратор также сохраняет доступ к истории в «Этапах».
5. Проверка правил: npm.cmd test. Все 5 тестов прошли в среде разработки. Синтаксис JS проверен. Проверить GUI в Chromium не удалось из-за политики среды; Windows/Electron и PostgreSQL нужно проверить локально.

.env, база PostgreSQL, desktop/main.js, иконки и настройки не изменяются. npm install/setup не требуются. Новая сборка Electron не нужна для основных страниц, загружаемых с сервера. Для обновления локального окна подключения при желании пересоберите оба установщика.
